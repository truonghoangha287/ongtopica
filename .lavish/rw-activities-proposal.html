UI Proposal · responding to the Cambridge YLE review

Four sentence-level activities for the Starters R&W paper

The review's headline gap: every activity today works on one isolated word. Cambridge Starters tests language inside sentences and pictures. These four new activities close that gap — each drawn in Ongtopica's own screen (owl, dots, speaker, amber Next) and built to reuse the existing 232 word images, audio, mascot and celebration systems. Tap the mockups — they're live.

📷 Word-bank cloze · R&W 4 📷 Picture-scene Q&A · R&W 5 Yes / No sentence match · R&W 1–2 Preposition picker · Starters grammar

The move this proposal makes

  • From “knows the word ball” → “reads the ball is on the box and answers about it.”
  • Same session engine, same 4-stage ladder — these become new ActivityTypes after the word-level stages.
  • No new look, no new dependencies. Every screen is the activity chrome you already ship.

How to read each mockup

  • Top-left ✕ · center dots · top-right 🦉 — the real in-session chrome.
  • Green = correct feedback, using --success. Amber Next → unlocks when the screen is solved.
  • Under each: what it tests, and the green line = what it reuses.

How it lands in the codebase

Each activity is one new ActivityType + one component in components/activities/, wired into the existing SessionPlayer switch. No engine rewrite.
